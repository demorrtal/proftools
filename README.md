# 🤖 Корпоративный Telegram-бот управления задачами и дедлайнами

Удобный Telegram-бот на **Python 3 (`pyTelegramBotAPI`)** и **SQLite** для распределения задач в команде, контроля дедлайнов и автоматических напоминаний. Не требует установки тяжелых C++/Rust компиляторов и работает на любых версиях Python.

---

## 📌 Основные возможности

1. **База сотрудников с регистрацией и контролем уникальности должностей:**
   - При первом запуске бот запрашивает:
     1. **Имя** (от 2 до 40 символов)
     2. **Фамилию** (от 2 до 40 символов)
     3. **Номер учебной группы** (например: `ИУ9-51Б`, `211-321`)
     4. **Должность** (кнопки в Telegram)
   - **Автоматическое скрытие занятых должностей:** в списке доступных кнопок отображаются только те роли, которые еще не заняты другими участниками команды.
   - Автоматически сохраняет Telegram username и chat ID.
   - Поддерживает команду `/reregister` для обновления данных.

2. **11 фиксированных должностей:**
   - Председатель
   - 1-й заместитель
   - 2-й заместитель
   - Руковод медиа
   - Руковод ивента
   - Руковод админки
   - Руковод партнерки
   - Зам по проектам
   - Завхоз
   - Секретарь
   - Руковод адаптеров

3. **Разграничение прав (только Председатель):**
   - Только **Председатель** может ставить задачи, закрывать их, продлевать дедлайны, просматривать архив выполненных задач и снимать сотрудников с должности.
   - У 1-го заместителя и остальных сотрудников стандартный доступ исполнителя.

4. **Просмотр личных задач («📌 Мои задачи»):**
   - У каждого зарегистрированного участника есть кнопка **«📌 Мои задачи»** (или команда `/my_tasks`), которая показывает только задачи, назначенные на его должность, либо на «ВСЕ».

5. **Снятие человека с должности («🗑️ Снять с должности»):**
   - Председатель может в один клик выбрать сотрудника из списка и снять его с должности с подтверждением действия. Пользователю приходит уведомление, а его профиль сбрасывается.

6. **Архив выполненных задач («✅ Выполненные задачи»):**
   - Председатель может просматривать список завершенных задач.

7. **Добавление бота в группу («➕ Добавить в группу»):**
   - Доступно **исключительно Председателю**. Если бота попытается добавить в группу любой другой пользователь, бот предупредит о нарушении прав и автоматически покинет чат.

8. **График уборки («🧹 График уборки»):**
   - Просмотр актуальных дат уборки кабинета. **Председатель** и **Завхоз** имеют права добавлять новые даты дежурств и удалять прошедшие.

9. **План работы профбюро («📊 План работы профбюро»):**
   - Удобная кнопка для перехода по прямой ссылке к Google Таблице с общим планом работы.

10. **Умная система напоминаний:**
   - Срабатывает за 5 дней, за 3 дня и за 1 день с простым понятным заголовком: **«⚠️ НАПОМИНАНИЕ»**.
   - При пропуске дедлайна отправляется алерт о просрочке исполнителю и срочный рапорт **Председателю**.

## 🚀 Как развернуть бота в домашних условиях

Главное преимущество архитектуры этого бота: он работает по технологии **Long Polling** (сам опрашивает сервера Telegram).
Это значит:
- ❌ **НЕ нужен** белый / статический IP-адрес.
- ❌ **НЕ нужны** доменные имена и SSL-сертификаты.
- ❌ **НЕ нужно** открывать порты на домашнем роутере (Port Forwarding).
- ✅ Бот работает из любой домашней сети, через Wi-Fi или даже раздачу с мобильного телефона.

---

### Вариант 1: Запуск на домашнем компьютере / ноутбуке (Windows)

#### Шаг 1. Получение токена бота
1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Введите название бота (например, `Моя Команда Задачи`) и юзернейм (должен оканчиваться на `bot`, например `org_tasks_super_bot`).
4. Скопируйте полученный **HTTP API Token** (выглядит как `7123456789:AAH...`).

#### Шаг 2. Настройка файла окружения
1. В папке с ботом найдите файл `.env.example`.
2. Переименуйте или скопируйте его как `.env`.
3. Откройте в Блокноте и вставьте ваш токен:
   ```env
   BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

#### Шаг 3. Быстрый запуск
Дважды кликните по файлу **`run_bot.bat`** (или запустите **`start_bot.ps1`** через PowerShell).
Скрипт автоматически:
- Проверит установку Python в системе (выдаст понятное сообщение со ссылкой, если Python еще не установлен).
- Создаст изолированное виртуальное окружение Python (`venv`).
- Установит все необходимые библиотеки из `requirements.txt`.
- Запустит бота с защитой от случайных падений (автоматический перезапуск через 5 секунд).

---

### Как сделать, чтобы бот работал 24/7 дома на Windows:

#### А. Настройка электропитания (чтобы ПК не засыпал)
1. Откройте **Параметры Windows** → **Система** → **Питание и спящий режим**.
2. Установите *«При питании от сети переводить в спящий режим»* → **Никогда**.
3. Если используете ноутбук: в *Панели управления* выберите *«Действие при закрытии крышки»* → **Действие не требуется**. Так ноутбук можно закрыть и положить на полку.

#### Б. Автозапуск при включении компьютера
**Простой способ (через автозагрузку):**
1. Нажмите комбинацию клавиш `Win + R`, введите `shell:startup` и нажмите Enter.
2. Откроется папка автозагрузки Windows.
3. Создайте ярлык для файла `run_bot.bat` и положите его в эту папку. Теперь при каждом включении или перезагрузке Windows бот будет запускаться автоматически.

**Профессиональный способ (фоновая служба Windows через NSSM):**
Если вы хотите, чтобы окно консоли не висело на рабочем столе, а бот работал как незаметная системная служба:
1. Скачайте бесплатную утилиту **NSSM** (Non-Sucking Service Manager) с сайта [nssm.cc](https://nssm.cc/).
2. Откройте PowerShell/командную строку от имени Администратора.
3. Выполните:
   ```cmd
   nssm install TelegramTaskBot
   ```
4. В появившемся окне укажите:
   - **Path**: `C:\Users\soleg\AppData\Local\agy\bin\telegram_bot\venv\Scripts\python.exe`
   - **Startup directory**: `C:\Users\soleg\AppData\Local\agy\bin\telegram_bot`
   - **Arguments**: `bot.py`
5. Нажмите **Install service**, затем запустите службу:
   ```cmd
   nssm start TelegramTaskBot
   ```
Теперь бот работает в фоне даже без входа пользователя в систему и сам перезапускается в случае любых сбоев.

### Вариант 2: Запуск на сервере Ubuntu 24.04 LTS из репозитория GitHub

Репозиторий проекта: **[https://github.com/demorrtal/proftools](https://github.com/demorrtal/proftools)**

#### Шаг 1. Клонирование и первый запуск на сервере
Подключитесь к серверу по SSH (`ssh root@IP_ВАШЕГО_СЕРВЕРА`) и выполните команды:

```bash
# 1. Клонируем проект из GitHub
sudo git clone https://github.com/demorrtal/proftools.git /opt/telegram_bot
cd /opt/telegram_bot

# 2. Настраиваем токен бота
sudo cp .env.example .env
sudo nano .env   # вставьте ваш BOT_TOKEN и сохраните (Ctrl+O, Enter, Ctrl+X)

# 3. Запускаем автоматический установщик
sudo bash install_ubuntu24.sh
```

Скрипт выполнит:
1. Установку необходимых системных пакетов (`python3`, `python3-venv`, `python3-pip`, `git`, `tzdata`).
2. Создание изолированного виртуального окружения `venv` и установку зависимостей.
3. Регистрацию и запуск службы `telegram-bot.service` в **systemd** с автозапуском.

---

#### Шаг 2. Обновление бота на сервере (всего 1 команда)
Когда вы вносите правки в репозиторий `demorrtal/proftools`, для обновления бота на сервере достаточно выполнить:

```bash
cd /opt/telegram_bot
./manage.sh update
```
*(Скрипт автоматически сделает `git pull`, обновит зависимости и перезапустит бота).*

---

#### Шаг 3. Полный автодеплой через GitHub Actions (CI/CD)
В проекте уже настроен файл рабочего процесса `.github/workflows/deploy.yml`. 
При каждом `git push` в ветку `main` GitHub может сам подключаться к серверу и обновлять бота:

1. Перейдите в настройки вашего репозитория:
   `https://github.com/demorrtal/proftools/settings/secrets/actions`
2. Добавьте секреты (**New repository secret**):
   - **`SERVER_HOST`**: IP-адрес вашего сервера (например `185.xxx.xxx.xxx`)
   - **`SERVER_USER`**: пользователь на сервере (например `root`)
   - **`SSH_PRIVATE_KEY`**: содержимое вашего приватного SSH-ключа (содержимое файла `id_ed25519` или `id_rsa`)
3. Теперь при любом обновлении кода на GitHub бот будет обновляться на сервере автоматически!

---

#### Шаг 4. Управление ботом на Ubuntu
В комплекте идет утилита быстрого управления **`./manage.sh`**:

```bash
./manage.sh status   # Проверить текущий статус бота
./manage.sh logs     # Смотреть живые логи (Ctrl+C для выхода)
./manage.sh restart  # Быстрый перезапуск службы
./manage.sh stop     # Остановить бота
./manage.sh start    # Запустить бота
./manage.sh update   # Обновить библиотеки из requirements.txt
```

Также можно использовать стандартные команды `systemctl`:
```bash
sudo systemctl status telegram-bot
sudo journalctl -u telegram-bot -f
sudo systemctl restart telegram-bot
```

### Вариант 3: Запуск через Docker / Docker Compose на Ubuntu 24

Если на вашем сервере с Ubuntu 24 установлен Docker:

1. Убедитесь, что в файле `.env` указан валидный `BOT_TOKEN`.
2. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```
3. Просмотр логов в реальном времени:
   ```bash
   docker compose logs -f
   ```
4. Остановка бота:
   ```bash
   docker compose down
   ```

## 📖 Руководство пользователя бота

### 1. Регистрация команды
- Каждый участник нажимает `/start` в личных сообщениях с ботом.
- Бот спрашивает **Имя**, затем **Фамилию**, а затем выводит список из **11 должностей**.
- После клика по должности регистрация завершена.

### 2. Привязка общего чата для задач «ВСЕ»
1. Добавьте бота в общий чат вашей организации/команды.
2. Сделайте бота администратором группы (чтобы он мог свободно отправлять сообщения).
3. **Председатель** или **1-й зам** пишет прямо в этом групповом чате команду:
   ```
   /set_group
   ```
4. Бот подтвердит, что группа привязана. Теперь все задачи для «ВСЕХ» и напоминания будут автоматически приходить сюда!

### 3. Создание задачи (Председатель и 1-й зам)
1. Нажмите кнопку меню **«➕ Новая задача»** или введите `/new_task`.
2. Введите суть задачи (например: *«Подготовить презентацию для спонсоров к пятнице»*).
3. Выберите исполнителей:
   - Можно нажать **«👥 ВСЕ»** для рассылки в общий чат;
   - Либо кликнуть одну или несколько конкретных должностей (например, *«Зам по проектам»* и *«Руковод медиа»*), после чего нажать **«✅ Готово / Далее»**.
4. Введите дедлайн:
   - Формат даты: `25.11.2026 18:00` или `25.11.2026` (до конца дня).
5. Бот моментально уведомит исполнителей о назначенной задаче и поставит таймеры напоминаний на 5 дней, 3 дня, 1 день и просрочку.

### 4. Контроль и список задач
- Нажмите кнопку **«📋 Список задач»** или отправьте `/tasks`.
- Бот покажет карточки всех актуальных задач со статусами (`🟡 В работе` или `🔴 ПРОСРОЧЕНА`).
- Под каждой задачей есть кнопки:
  - **«✅ Выполнено»** — завершает задачу, снимает напоминания и уведомляет исполнителей.
  - **«⏳ Продлить дедлайн»** — позволяет ввести новую дату, если сроки сдвинулись.
